## 四、吸收态改动的效果（交接单自查第 3 条的替代检验）

第 3 条自查原本要求 base 与 relax2 两组产出不得逐位相同，需两组才能做。
本轮用 v4 的 base（冷却 2 年）与 v6 的 base（吸收态）在同一分母下对比：

- **7 个 α 无一逐位相同**——吸收态确实改变了轨迹，改动生效了。
- 但得分差为 −0.063 至 +0.044，**正负不一致，且全部落在种子离散范围内**。
- `Expire` 项几乎没动（v4 均值 −3.066，v6 −3.131）。

结论：冷却期规格（2 年 vs 规划期内吸收态）**不是主结果的驱动因素**。
这对论文是好事——主张不依赖那个无条文依据的冷却期设定；但也意味着
把它作为敏感性轴的信息量有限，relax0/relax5 两组的优先级可以下调。

## 六、脚本修复

驱动脚本在本组收尾时崩于 `line 140: NAME?: unbound variable`。根因是 locale：
UTF-8 下 bash 把紧跟变量的中文全角括号首字节并入变量名，C locale 下不会。
本机 bash 工具的 locale 是 C，故干跑一直通过，后台进程继承 UTF-8 一跑正式的就崩。
已把 `run_batch_v6.sh` 与 `run_batch_v4.sh` 中变量紧跟非 ASCII 字符的 6+6 处改为
`${VAR}` 形式，并在 C 与 en_US.UTF-8 两种 locale 下各干跑一次通过。
崩溃发生在训练与写盘之后，数据未受影响。
