## L0 环境一致性

同一个计划下 `Σ EV[u, 立项年]` = 892.5997，环境实付的折现奖励流 = 892.5997，
**差 1.14e-13**；外加 `TimingWorld.validate()` 的机械自证。
脚本里是 `assert`，不一致就拒绝训练 —— 不能重演"环境 reward ≠ oracle 计价
≠ RL target"那种错误。

## 两处实现问题（都是我第一版写错、已修）

1. **Double-Q 失效。** 第一版两个估计器的预测**最大绝对差恰好为 0**，
   两套目标也完全相同。原因是 ExtraTrees 在训练点上几乎插值，两个森林都
   精确复现目标，于是 argmax 永远一致（加上第 0 轮 `ya = yb` 共享同一数组）。
   仅换随机种子无效 —— 必须让两个估计器拟合**互不相交的一半转移**
   （按年整组切分，同年候选行不跨侧，否则"独立"名不副实）。
   修正后 A/B 最大差 140~153，约 0.26~0.29 个标准差。
   **但成绩没变**（α=0.5 下仍 0.880）—— 说明高估修正不是这里的瓶颈，
   这一点值得记下，免得以后误以为 Double 是关键。
2. **一处必须声明的近似。** 数据由行为策略按批次推进，故对某个候选 u
   只能拿到行为策略实际到达的下一年状态，而非"假如只选了 u"的反事实状态。
   本实现用同一条轨迹的下一年候选集合（去掉 u）近似 s'。
   这是 batch FQI 的标准做法，但**是近似而非精确回溯，论文方法部分须写明**。

## L2 合成实验（24 地块 / 10 年 / 每年 2 名额，3 种子）

| α | 随机 | 纯空间排序 | 时间感知贪心 | **Double-FQI** | oracle |
|---:|---:|---:|---:|---:|---:|
| 0.25 | 0.792 | 0.905 | 0.939 | 0.934 ± 0.009 | 1.000 |
| 0.50 | 0.669 | 0.771 | 0.880 | **0.880 ± 0.000** | 1.000 |
| 0.75 | 0.531 | 0.621 | 0.962 | **0.962 ± 0.000** | 1.000 |
| 1.00 | 0.377 | 0.453 | 0.941 | **0.941 ± 0.000** | 1.000 |

* **Gate A 通过**：每个 α 都高于纯空间排序，α≥0.5 时差距很大（0.880 对 0.771、
  0.962 对 0.621、0.941 对 0.453）。
* **Gate B 通过**：α≥0.5 时与时间感知贪心**逐位相同**（价值、Where 召回、
  When MAE 三项都一样，三个种子标准差 0.000）。
* **Gate C 不通过**：从未超过时间感知贪心。

### 为什么在小世界里恰好相等（诊断，不是猜测）

Q 与即时价值的**全局**秩相关只有 +0.474（α=0.5）与 −0.040（α=1.0），
但**年内**秩相关是 **+0.969 / +0.978**；Q 的年内极差 44~54，
而年份之间的落差是几百。

也就是 Q ≈（随年份变化的大项）+（年内几乎就是即时价值的排序）。
**延续项在年内近似常数，因此不可能改变 top-K 选择** —— 策略必然与
时间感知贪心重合。小世界里 24 个地块抢 20 个名额、候选集只有 24，
"选了 u 就少一个候选"这一效应太弱，跨年协调没有发挥空间。
这与上一轮 Gate 4 的发现同源（候选:名额比决定等待/协调有无价值）。

## L3/L4 光明区（717 单元 / 25 年 / 每年 3 名额 / 只押 Floor / K=20，3 种子）

三条基线的数值与 v19 那张表**逐位一致**（0.757 / 0.775 / 0.894，oracle 6876），
故可直接并列比较。

| 方法 | 相对 oracle | 区间 | 挑错单元（Where） | 放错年份（When） |
|---|---:|---|---:|---:|
| 随机 | 0.757 ± 0.061 | 0.716–0.827 | 459 | 1210 |
| 静态 / 近视贪心 | 0.775 | — | 342 | 1208 |
| BC（v19 监督时空打分器） | 0.846 ± 0.024 | 0.819–0.863 | 254 | 805 |
| 时间感知贪心 | 0.894 | — | 124 | 608 |
| **Double-FQI** | **0.904 ± 0.006** | **0.897–0.907** | **119** | **545** |
| oracle | 1.000 | — | 0 | 0 |

逐种子：0.9073 / 0.9064 / 0.8969；挑错单元 126.7 / 112.6 / 116.3；
放错年份 510.6 / 531.1 / 592.9；三个种子都立项满 75 个。
训练样本 15000 个 (状态, 候选) 对（每种行为策略 10 个回合）。

按第 17 节的区间划分，这落在 **`.894 < Double-FQI < 1.0`**，即

> RL learns sequential coordination beyond a temporal heuristic.

而且**改善主要在 When**（放错年份 545 对 608，−10%），Where 略好
（119 对 124）。Q 与即时价值的全局秩相关 0.882 —— 明显小于 1 且成绩更好，
说明它学到的不只是当期价值的复述。

**与合成世界相反的方向正好互相解释**：容量咬得紧（717 抢 75）时，
"这一年的名额给谁"会改变后续可选集合，延续项才在年内产生差异；
小世界候选太少，这一项退化成常数。
