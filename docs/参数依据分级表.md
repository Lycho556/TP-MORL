# TP-MORL 参数依据分级表

**用途**：对外说数、写方法学章节、答辩答疑的唯一口径。凡引用参数，先查本表的"证据等级"。

**核对日期**：2026-09-03 · **核对来源**：`src/tpmorl/env/schedule.py`、`src/tpmorl/rl/env_gym.py`、`src/tpmorl/objectives/reward.py`、`data/processed/gm_dataset_v1/temporal_v0/calib.json`、`docs/*.md`（代码与 calib.json 三处一致）

证据等级定义：

| 等级 | 含义 | 对外说法 |
|---|---|---|
| **A 条文** | 法规/规范性文件明文规定 | "依据……规定" |

## A 级：有条文依据（2026-09-03 已从官方发布页逐字核对，见 `条文原文_更新单元计划有效期.md`）

| 规则 | 取值 | 出处（已核实） |
|---|---|---|
| 计划有效期 | 自公告之日起 **2 年** | **深规划资源规〔2019〕4 号第三十二条**《深圳市拆除重建类城市更新单元计划管理规定》 |
| 延期 | 确需延期可申请 **延期 1 年，原则上仅可延期一次** | 同上，第三十二条 |
| 适用范围 | 仅适用于**本规定施行后**（2019-03-15 起）批准的计划，不含重点更新单元计划 | 同上，第三十二条 + 第五十一条 |
| 政府原因顺延 | 经区政府审查确认因政府原因超期的，**单次顺延不超过 1 年** | 深建规〔2025〕4 号（二） |
| 报送节点 | 至少在有效期**届满前 3 个月**报送更新单元规划草案 | 深建规〔2025〕4 号（二） |
| 失效条件 | 草案公示结束之日起 **3 个月**内规划未获批准、且已过有效期并未完成延期 → 由区更新部门公告失效 | 深建规〔2025〕4 号（二） |
| 存量补设 | 公告未明确有效期的计划，各区应在 2025-04-09 起 **30 日内**按 2019〕4 号统一补设有效期 | 深建规〔2025〕4 号（二） |

**三条核对结论**：

1. **出处归属已更正。** "有效期 2 年 / 延期 1 年"原先记为深建规〔2025〕4 号，实为**深规划资源规〔2019〕4 号第三十二条**。2025〕4 号不设定有效期长度，只规定补设、顺延、报送节点与失效认定。
2. **法定窗口上限 3 年（2+1），模型用 5 年（`TAU_VALID`3 + `TAU_EXT`2）。** 不矛盾，理由在条文自身：第三十二条只管 2019-03-15 之后批准的计划，而标定样本是 2010–2018 年配对，当期适用深规土告〔2010〕16 号，**本无有效期之设**——2025〕4 号需专门处理"公告未明确有效期"的存量计划，正是旧计划无有效期的直接证据。故实测中位 3 年不是条文与现实脱节，而是旧制度下无此限；论文应把 2019 年后的 3 年上限作为情景对照。
3. **"冷却期"两份文件中均无规定**（全文检索"冷却"0 处、"重新申报"0 处）。`COOLDOWN` 属 C 级。

## 对外说数的三条纪律

1. **不要把 vit-main 的设定与结果说成本项目的。** vit-main 是前一版（T=8 等长期、312 parcel、7 目标、七维偏好向量条件化）；TP-MORL 是 15 年逐年、717 单元、11 目标、单一 α 旋钮。1985–2021 历史回测、readiness 图层、Moran's I、二次拆建率、抗冲击时间等结果**全部出自 vit-main，TP-MORL 未做过**。
2. **TP-MORL 当前结果不可对外引用。** `docs/honest_assessment_v1.md`：Floor 目标输给随机基线、前沿仍被支配、曲线未收敛；且刚修完 CCM 对角线导致的 18.2% 免费动作缺陷，正在按 `docs/rerun_v2.md` 重跑。
3. **C 级参数一律说"设定值，须敏感性分析"**，不说"依据"或"标定"。尤其 `COOLDOWN` 无任何条文或数据依据——外部专家若被问及"冷却期条文"，会找不到对应规定。
