# v19 简化框架：Where + When 的本地小测试

按"收回复杂框架、只证一句话"的要求重做。主线只保留一句：

> **当城市更新机会在时间上变化时，纯空间排序不足以复现最优的时空分配。**

降级为附录证据（不再进主线）：等待/STOP、GAE vs MC、PBRS、初筛 K 扫描、
容量后悔、秩反转、BC 诊断矩阵、actor 学习率与冻结、critic 诊断、
18 地块双压力世界、动作空间诊断。

**结论一句话：合成实验完整通过；光明区通过，但通过它的是"监督时空打分器"，
不是 400 迭代的 PPO ——后者在 3 个种子里崩掉 2 个。**

## 一、合成实验（`scripts/exp_where_when.py`）

### 世界构造：空间与时间分离

    第 t 年立项地块 i 的价值 = S_i · [(1−α) + α·T_{i,t}] · γ^t

24 个地块 / T=10 / 每年 2 个名额（20 个名额 < 24 个地块，故"挑谁"与
"哪一年"同时有约束）。窗宽 1.8 年，四个空间适宜性档 {1.0, 0.8, 0.6, 0.45}。

**判别力的关键设计**：S_i 分档，且**每一档内部都同时含有早峰 / 晚峰 /
很晚峰**（峰值年 0.7 / 6.3 / 10.9）。

* 档与档之间 —— 纯空间排序有真实信号（高 S 的确更值钱），它是一个有意义的
  基线而不是随机；
* 同一档内部 —— S 完全并列，**只有时间能区分**，这正是 "when"。

若让"高 S 的恰好都该早做"，纯空间排序会白捡一个正确的时序，实验就测不出东西。

口径自证：`TimingWorld.validate()` 机械校验"世界实付的折现奖励流 = dvalue"
（单地块单动作走一遍，不等即报错）。这条防线来自上一轮的教训——
当时给价值加"读交付年"却漏改 `step()` 的结算，两套口径打架，
结论整组作废。现在"价值读哪一年"只有一个定义 `value_year()`，奖励与 oracle
共用它。

### 结果（3 种子 × 250 迭代）

| α | 随机 | 纯空间排序 | 时间感知贪心 | **TP-MORL** | oracle |
|---|---:|---:|---:|---:|---:|
| 0.00 | 0.880 | 1.000 | 1.000 | **1.000** | 1.000 |
| 0.25 | 0.792 | 0.905 | 0.939 | **0.967** | 1.000 |
| 0.50 | 0.669 | 0.771 | 0.880 | **0.979** | 1.000 |
| 0.75 | 0.531 | 0.621 | 0.962 | **0.976** | 1.000 |
| 1.00 | 0.377 | 0.453 | 0.941 | **0.971** | 1.000 |

**两条成功标准都满足**：TP-MORL 在每个 α 上都高于纯空间排序，且始终 ≈ oracle
（0.967~1.000）。α=0（机会在时间上不变）时四者全部 = 1.000——消融的对照端干净，
说明差距确实来自时间维度而非别的东西。

### Where / When 分解（α=1.0）

| 方法 | Where 召回 | When MAE | When 1 年内 |
|---|---:|---:|---:|
| 随机 | 0.796 | 2.80 | 0.33 |
| 纯空间排序 | **0.889** | **2.75** | 0.25 |
| 时间感知贪心 | 0.889 | 0.75 | 0.75 |
| **TP-MORL** | **1.000** | **0.67** | **0.89** |
| oracle | 1.000 | 0.00 | 1.00 |

这一张表就是标题里两个词各自的支撑：**纯空间排序把"挑谁"挑对了（召回 0.889）
却把"哪一年"放错了（MAE 2.75 年）**；加入时间信息后 When MAE 降到 0.67。

口径说明：Where 召回与 When MAE 都相对 oracle 计划算，且 When 只在
"两者都选中"的地块上算——否则"没选中"会混进时间误差，两个维度就分不开。
三个种子的 TP-MORL 标准差为 0（小世界上确定性 argmax 推演收敛到同一计划）。

## 二、光明区实验（`scripts/exp_temporal_gate.py`）

717 单元 / T=25 / 每年 3 名额 / 只押 Floor / 预算不咬 / 年度初筛 K=20 /
每个单元固定一个目标功能 / 3 种子。oracle = 6876（名额约束下的精确指派）。

| 模型 | Where | When | 相对 oracle | 区间 | 挑错单元损失 | 放错年份损失 |
|---|---|---|---:|---|---:|---:|
| 随机 | ✗ | ✗ | 0.757 ± 0.061 | 0.716–0.827 | 459 | 1210 |
| 静态 / 近视贪心 | ✓ | ✗ | 0.775 | — | 342 | 1208 |
| PPO 随机初始化 400 迭代 | ✓ | 部分 | 0.796 ± 0.035 | 0.756–0.822 | 601 | 798 |
| **监督时空打分器（BC）** | ✓ | ✓ | **0.846 ± 0.024** | 0.819–0.863 | **254** | 805 |
| BC→PPO 400 迭代 | — | — | **0.474 ± 0.401** | **0.029–0.806** | 3014 | 602 |
| 时间感知贪心 | ✓ | ✓ | 0.894 | — | 124 | 608 |
| oracle | ✓ | ✓ | 1.000 | — | 0 | 0 |

三条读数：

1. **监督时空打分器在 3/3 种子上超过静态基线**（0.846 对 0.775，缺口收窄
   +0.394 / +0.197 / +0.360），挑错单元损失 254 < 静态的 342，
   距 oracle 指派年 MAE 2.55 < 静态的 3.31。**Where 与 When 同时改善**，
   这正是指南第 33 节那张表要的"两者都下降"。
2. **在它之上再跑 400 迭代 PPO 会崩**：0.806 / 0.588 / **0.029**，
   标准差 0.401。这不是计价假象——已用环境自身的折现奖励流核对过，
   两套口径对三个策略的排序完全一致（近视 48.9M / 时间感知 59.1M /
   BC→PPO 47.3M，与 EV 计价同向）。**退化是真实的。**
3. PPO 随机初始化 400 迭代（0.796）与静态（0.775）的差落在种子噪声内，
   且该档下随机的区间 0.716–0.827 跨过了静态的 0.775——**初筛档的判别力偏弱**，
   这一行不能单独当证据。

### 一处必须记下的实现细节

监督初始化时**必须把末行"今年到此为止"也作为监督样本、目标取 0**。
指南建议"BC 不学 STOP"（把时序留给 RL），在 18~24 个候选的小世界里无害，
但在 717 单元这一侧会直接崩：只训真实候选行时 STOP 的打分未经校准，
初始化后它压过所有真实候选，一年只立项几个 —— 实测 0.147（低于随机 0.716）、
挑错单元损失 3926、立项数 40 而非 75，且**按种子崩**（同一版本 seed 1 正常）。
取 0 不是调参：EV 全为正，"今年不做"的当期价值就是 0，
故学到的序是"任何正价值的候选都优于停"；何时真的该停仍由 RL 决定。

## 三、据此建议的论文写法与下一步

### 故事线

沿 Liang et al. (2018) 的纪律：机制 → 历史验证 → 未来情景。本文的机制是
**Where + When**：静态方法回答"在当前条件下该更新哪里"，本框架回答
"该更新哪里、以及在哪一年"。合成实验证明机制可学（TP-MORL ≈ oracle，
且随时间变化增强而与纯空间排序拉开：0.453 对 0.971），光明区证明它在真实城市
里有意义（监督时空打分器 0.846 对静态 0.775，Where 与 When 同时改善）。

**不要把"RL 超过所有方法"写进主张**。时间感知贪心 0.894 仍高于所有学习模型；
论文的主张应当是"框架学到了正确的时空分配模式"，这与指南第 9、26 节一致。

### 上服务器前必须先在本机解决的一件事

**不要在服务器上跑 400 迭代的 BC→PPO**：3 个种子崩 2 个。
先在本机做一条"训练长度 — 表现"曲线（0 / 10 / 50 / 150 / 400 迭代，
1~2 个种子），确定一个保住打分器的早停点。已有的两个数据点提示窗口存在：
2 迭代时 0.798（挑错单元损失 258）、400 迭代时崩溃。
这一条做完再上服务器。

### 明确不做

按指南第 19、48 节：不再扫 γ / GAE λ / 熵 / actor 学习率 / 冻结 actor /
PBRS / 初筛 K；不再加机会场机制；不做 Act/Wait 分层
（上一轮已实测：真实环境前 8 年 Δ等 全为负，该决策被严格支配）。
