# 时序状态机与年度动作掩码 v0

**目的**：把"计划有效期、法定顺位、年度配额"编码为 MDP 的转移与掩码，使 agent 必须回答
"这个单元现在动、还是再等"。这一步不依赖任何待补数据，全部参数或由实测标定、或显式标为超参数。

代码：`src/tpmorl/env/schedule.py`（状态机）、`src/tpmorl/data/build_temporal.py`（生成与对照）
产物：`data/processed/gm_dataset_v1/temporal_v0/`

## 1 状态机

每个候选更新单元独立走一个六态自动机：

| 态 | 含义 | 可用动作 |
|---|---|---|
| S0 | 未立项 | 立项（受年度配额约束） |
| S1 | 计划有效期内，τ 年倒计时 | 推进 / 等待 |
| S2 | 单元规划已批，待实施 | — |
| S3 | 实施中 | — |
| S4 | 已完成 | 终止态 |
| S5 | 计划失效，冷却期 N 年 | **完全不可动** |

**S5 是整个机制的关键。** 现有 RL 里"不动"是零代价的空动作；引入 S1→S5 之后，
立了项却未能在有效期内获批，会把单元推入冷却期而彻底失去可动性。于是"等"成为一个
有真实风险的决策，agent 必须权衡期权价值——这正是纯空间优化模型无法建模的部分。

## 2 参数标定

### 实测标定

| 参数 | 取值 | 来源 |
|---|---|---|
| HAZARD | 0.174 / 0.212 / 0.239 / 0.277 / 0.179 | 109 对"计划公告→单元规划批准"配对，逐年由累计获批数反解：19/109、(38−19)/(109−19)、(55−38)/(109−38)、(70−55)/(109−55)、(77−70)/(109−70) |
| τ 有效期 | 3 年 | 配对时滞**中位数恰为 3.00 年**（均值 3.91，四分位 1.75–5.25，范围 −0.50–11.75） |
| τ 延期上限 | +2 年（总 5 年） | 累计获批比例：1 年 17.4%、2 年 34.9%、3 年 50.5%、4 年 64.2%、**5 年 70.6%** |
| 年度配额 | 3 个/年 | 光明区 2011–2018 计划公告**均值 3.1、上限 6**（2010 年 9 条为积压年，剔除） |

**一个重要的实证否证**：名义有效期常被引作 2 年，但只有 **34.9%** 的单元在 2 年内获批。
现实中延期与重新申报是常态，因此把 τ 硬设为 2 年会系统性高估失效率。
τ=3+2 覆盖 70.6% 的案例，余下 29.4% 视为经"失效→冷却→重新申报"路径。

### 超参数（无实测数据，须做敏感性分析）

`BUILD_YEARS=3`（S2→S4 的实施周期）、`COOLDOWN=2`（S5 冷却年数）。
平台目录中没有单元实施进度或竣工验收数据，这两个值不能标定，只能扫。

### 数据瑕疵

配对时滞最小值为 **−0.50 年**（批准早于公告），属名称匹配噪声，1 例。逐年 hazard 反解基于
累计获批数而非原始时滞值，该例不影响标定结果。

## 3 掩码验证与实证对照

基线策略（按更新压力贪心用满配额，有效期内每年推进）跑 15 年：

| 指标 | 基线 | 实证（光明区 2010–2018） |
|---|---|---|
| 年均立项 | 3.0（配额封顶） | 3.8 |
| 年均获批 | 1.5 | 2.0 |
| 立项→获批转化率 | 22/45 = 49% | 18/34 = 53% |
| 失效比例 | 13/45 = **29%** | — |
| 被选中单元中产业通道占比 | 48.6% | 39.0%（全市已批单元） |

**一项自洽性检验通过**：模拟失效率 29% 与生存曲线推出的 29.4%（τ≤5 未覆盖的比例）吻合。
两者是独立路径得到的——前者来自 15 年蒙特卡洛轨迹，后者来自累计获批曲线。

**图 a 的两条曲线重合是构造使然**（hazard 由该曲线反解），最大偏差 0.05 个百分点，
这是实现正确性检查，**不是独立验证**。真正的外部验证需要留出年份做样本外检验，待做。

**基线暴露的近视**：贪心策略 15 年内一次都没有碰农转用储备（P5，295 个单元），
因为该通道压力代理值系统性偏低。但农转用是唯一能提供大宗增量用地的通道，
其价值在于长期而非当期——这正是折扣累积奖励下 RL 应当学到、而压力贪心学不到的东西。

## 4 与竞品的形式化差别

| | pSO / MOGNNAC / LUP-PPO | 本方案 |
|---|---|---|
| 动作 | 每格选一个用地类别 | (选中单元, 目标功能)，目标功能可选集由通道决定 |
| 约束 | 面积配比等静态约束 | 状态相关掩码：配额、有效期、冷却期、通道 |
| "不动" | 零代价空动作 | 有期权价值，且可能触发失效 |
| 产出 | 一张最优用地图 | 逐单元逐年的 Q(动)−Q(等)，即行动日程表 |
