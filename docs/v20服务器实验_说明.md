# v20 服务器实验：设置、启动与口径

一句话启动（分支 `v20-fqi-dev`）：

    nohup bash ~/TP-MORL/启动实验_v20服务器.sh > ~/v20.log 2>&1 &

每个阶段结束**自动 commit + push + 打标签**，备注里带该阶段的关键数字表，
可独立读懂。断点续跑：已有汇总 CSV 的阶段自动跳过（`FORCE=1` 强制重跑）。
单段失败不中断后续，状态写进 `RUN_STATUS.md`；push 失败只告警、结果仍在本地提交。

常用开关：

    STAGES="S1 S2"   只跑指定阶段（默认全跑）
    FAST=1           冒烟模式，十几分钟跑完全流程（本机已验证）
    FORCE=1          忽略已有结果
    SEEDS="0 1 2"    覆盖主实验种子
    NO_PUSH=1        只 commit 不 push

## 冻结协议

服务器实验期间**不得修改**：`env_gym.py`、`schedule.py`、`opportunity.py`、
`reward.py`、oracle、评价指标；也不要再调 gamma、树的棵数与深度、reward scaling、
STOP、PBRS、prescreen、机会场幅度与窗宽。

理由是这一版实验的卖点正是

> 同一个 MDP + 同一个 reward + 同一个 oracle + 同一套评价指标，只更换 learner。

启动脚本每次跑批前做 L0 自证：同一计划下 `Σ EV[u, 立项年]` 必须等于环境实付的
折现奖励流（本机实测差 1.14e-13），不等直接中止 —— 上一轮就吃过"环境按立项年
付钱、oracle 按交付年计价"的亏，整组结论作废。

## S4 历史回测为什么是 BLOCKED

指南设计的是 1985–2009 训练 → 2010–2021 留出验证。**本仓库数据不支持**，
三条都不满足（`scripts/check_historical_data.py` 会把实测覆盖写进
`results_srv_s4/S4_STATUS.md`，退出码 3 区别于失败）：

1. **时间覆盖不足**：光明区街道年面板只有 2010–2018 有非零记录（共 34 条、
   4 个街道），2010 年前没有记录、2019 年起全为 0。没有 1985–2009 可训。
2. **粒度对不上**：记录是街道 × 年的汇总计划数；`gm_renewal_units.csv` 的
   52 个具名项目没有 uid，候选单元表也没有街道字段，无法落到 717 个候选单元。
3. **循环论证**：`temporal_v0/calib.json` 写明 hazard 来自 109 对"计划公告→
   单元规划批准"配对、`tau_valid` 来自配对时滞中位数、`quota=3` 来自
   "光明区 2011–2018 计划公告均值 3.1" —— 这批记录**已被用作标定输入**，
   再当留出集不成立。

解锁所需数据（按优先级）：① 更新单元计划批次名单，含单元边界或地块坐标
+ 公告年份；② 或退一步，候选单元的街道归属字段（只够做描述性对照，
4 街道 × 9 年 × 34 事件不足以支撑"精度改善"的论断）；③ 2019 年以后的公告记录。

拿到 ① 之后，S4 才能按指南写成真正的时间留出回测。

## 两处必须随结果一起出现的口径声明

1. **S3 的两档筛选不得混用。** `0.726 / 0.912` 那组是**无初筛**档测的，而
   Double-FQI 的 `0.904` 是**初筛 K=20** 档测的。脚本把两档分开算、分开报，
   FQI 只出现在初筛档那张表里。
2. **S5 的机会场全部是情景参数、无实证标定**（单元表没有建成年份、历年规划
   定位与设施投用年份）。结论只能写成条件句："若设施提前到位，则模型建议的
   立项时点前移 X 年"，不得写成对光明区未来的预测。
   另注：`立项年重心` 在配额年年咬满时是构造常数（恒为 (T−1)/2），
   不可当结果报；有信息量的是与基线逐单元对比的 When 平移量。

## 第一批结果只需检查三件事

1. Double-FQI 是否仍稳定在约 **0.90**；
2. 是否仍高于时间感知贪心（本地 0.904 对 0.894）；
3. 放错年份是否仍明显低于时间感知贪心（本地 545 对 608）。

三条都成立就不要再碰主模型，直接进入 S5 与论文写作。
本地 3 种子参照：随机 0.757 / 静态 0.775 / BC 0.846 / 时间感知贪心 0.894 /
Double-FQI 0.904 ± 0.006 / oracle 1.000。
