# 光明区功能区重构方案 v0 —— 以「制度通道 × 时序状态」取代「用地类型分区」

> 本文回答一个问题：为了让 RL agent 能学"什么时候动哪块地"，而不是"理想状态下这块地该是什么"，
> 功能区应该怎么划。结论是**推翻用地类型分区**，把用地功能从"分区属性"降级为"决策变量"，
> 把"制度通道 + 时序位置"升级为分区属性。

---

## 0 结论先行

| | 旧做法（pSO / 现有 RL 工作） | 本方案 |
|---|---|---|
| 分区依据 | 12 类用地类型 | 7 类**制度通道** × 6 类**时序状态** |
| 用地功能的角色 | 分区身份（要优化的对象） | **动作的目标值**（决策变量） |
| 决策对象 | 27,531 个格子各自选类别 | **717 个候选更新单元**整体立项 |
| 决策内容 | "这块地该是什么" | "这个单元**现在动、还是等**；若动，转成什么" |
| 问题类型 | 静态多目标空间配置 | **空间耦合的多目标最优停止（optimal stopping）** |
| 产出 | 一张最优用地图 | 一张**可执行的行动日程表**（哪年动哪些单元） |

关键判断：既有 RL 方法把所有地块当作"同一时刻可自由重分配的白板"，这在新区规划成立，在存量更新
里根本不成立。存量更新的约束不在"这块地适合做什么"，而在"这块地什么时候**允许**被动、动了要付多少
代价、不动会不会错过窗口"。**这三件事全部是时序量，全部不在用地类型里**，所以用地类型不该当分区。

---

## 1 为什么要推翻：三条实测证据

### 1.1 用地类型分区把"决策对象"和"决策内容"混为一谈

12 类中有 3 类（RC 商住混合、CBD 中心商务、IH 工业配套）在光明区**格数为 0**。剩下 9 类里，
限建 7.0% 是既有道路市政（不可动）、生态 35.6% + 农业 24.8% 是尚未建成的地。真正处在"存量更新"
状态的只有居住 9.1% + 商服 2.8% + 产业 16.9% + 设施 3.8% = **32.6%**。
把这 32.6% 和另外 67.4% 用同一套类别体系描述，等于要求 agent 用同一个动作空间同时处理
"拆掉一个 1990 年代的工业区"和"把一片农田转成建设用地"——这两件事的法定程序、时间尺度、
成本量级、参与主体全都不同。

### 1.2 真实的更新是按「制度通道」发生的，不是按用地类型

全市 269 条已批城市更新单元规划按项目名称归类：

| 通道 | 单元数 | 占比 | 拆除用地合计 | 中位规划容积率 |
|---|---|---|---|---|
| 工业 / 厂区 / 科技园 | 105 | **39.0%** | 648 ha | 6.47 |
| 片区（混合，多含工业） | 72 | 26.8% | 872 ha | 6.72 |
| 村 / 新村 | 46 | 17.1% | 455 ha | **7.24** |
| 旧屋村 / 旧村 / 老村 | 12 | 4.5% | 117 ha | 6.74 |
| 轨道交通设施 | 1 | 0.4% | 128 ha | 6.33 |

两点决定性含义：
1. **产业用地是深圳存量更新的第一通道**（39%，近四成）。这不是"工业地块恰好较多"，
   而是"工改工 / 工改商住"是制度上最畅通的路径。分区必须把它单列。
2. **不同通道的容积率结果系统性不同**：村 / 新村中位 7.24，比工业类 6.47 高 0.77。
   村集体用地的更新要以更高开发强度换取拆迁补偿——这是**通道决定奖励函数参数**的直接证据，
   用地类型分区完全无法表达。

光明区 18 条已批单元同样如此：工业类 7 条 43.6 ha，片区 7 条 170.4 ha，旧屋村 2 条 9.3 ha。

### 1.3 单元尺度决定了动作必须以"单元"为单位，不是格子

光明区已批单元拆除面积中位 4.4 ha（= 4.4 个 100 m 格）。按格子决策会产生 12,454 维动作空间，
且允许物理上不可能的"半个单元"动作。按单元决策：**717 个候选体，格数中位 11，全部落在
实证的 1–30 格区间内**——动作空间小了一个半数量级，而且每个动作都对应一个法律上真实存在的对象。

## 2 新分区定义

### 2.1 轴 A —— 制度通道（谁能动、依什么法、什么时钟）

| 编码 | 通道 | 格数 | 占区内 | 时钟 | 可用动作 |
|---|---|---|---|---|---|
| P0 | 刚性禁动 | 4,915 | 28.3% | 无 | 无 |
| P1 | 产业拆除重建 | 2,469 | 14.2% | 计划有效期倒计时 | 立项 / 推进 / 放弃 |
| P2 | 旧居住通道 | 1,208 | 7.0% | 协议谈判周期 | 拆除重建 / 综合整治 / 等待 |
| P3 | 商服提升 | 339 | 2.0% | 无硬期限 | 整治 / 等待 |
| P4 | 设施存量 | 532 | 3.1% | 专项规划周期 | 改扩建 / 等待 |
| P5 | 农转用储备 | 3,537 | 20.4% | 年度用地指标 | 转用 / 保留 |
| P6 | 生态保育 | 4,369 | 25.2% | 无 | 无 |

分区的定义性特征是**动作空间与时钟**，不是用地内容。P0 与 P6 合计 53.5% 是 agent 完全不能动的
——这是"已建成区域"与"从零规划新区"最本质的差别，而它在旧分区里是隐形的。

### 2.2 轴 B —— 时序状态（在时钟的哪个位置）

每个候选单元 u 在每期 t 处于以下之一，构成一个**制度自动机**：

| 状态 | 含义 | 转移条件 |
|---|---|---|
| S0 未立项 | 尚无更新单元计划 | agent 选择立项 → S1 |
| S1 计划有效期内 | 已公告，τ 年倒计时 | agent 推进 → S2；τ→0 → S5 |
| S2 单元规划已批 | 待实施 | 实施 → S3 |
| S3 实施中 | 施工，产生干扰 | 期满 → S4 |
| S4 已完成 | 功能已变更 | 终止态（本回合内不可再动） |
| S5 计划失效 | 冷却期 N 年 | N 年后 → S0 |

**S5 是本方案的机制核心**：现有 RL 里"不动"是零代价的空动作；引入 S5 后，
立项但未在有效期内推进会把单元推入冷却期，在冷却期内**彻底失去可动性**。
这使"等"变成一个有真实风险的决策，agent 必须权衡期权价值。

### 2.3 功能区 = (通道, 状态)，用地功能是动作的目标值

六类压缩功能（从 12 类合并，依据是更新实际转换的目标）：
`R 居住(1,2) | C 商服(3,4,5) | I 产业(6,7,8) | U 设施(12) | A 农业(9) | E 生态绿地(10,11)`

一个单元的完整描述是 `(通道 P1, 状态 S1, τ=2 年, 现状功能 I, 目标功能待定)`。
agent 的动作是 `(选中 u, 目标功能 f)`；`f` 的可选集由通道决定
（例如 P1 允许 I→I/C/R，P6 不允许任何 f）。

## 3 MDP 重写

**状态** `s_t`（按单元组织，共 717 个单元 + 全局量）
```
每单元:  通道 c_u (7 类 one-hot)
         时序状态 σ_{u,t} (6 类 one-hot)
         剩余有效期 τ_{u,t} ∈ {0..T_valid}
         现状功能比例 p_{u,t} ∈ Δ^6          ← 直接喂 pSO 可微目标函数
         邻域聚合 pool(p)_{u,t}               ← pSO 的 meanP 算子
         更新压力 press_{u,t}
         上次变更距今年数 age_{u,t}
全局:    年份 t，年度立项配额剩余 K_t，在建单元数
```

**动作** `a_t`：从 `{u : σ_{u,t} ∈ {S0,S1}}` 中选不超过 `K_t` 个单元，各配一个目标功能 `f`；
`a_t = ∅`（全部等待）始终合法。动作掩码由 `(c_u, σ_{u,t}, τ_{u,t})` 直接生成——
**这就是"法规时序约束嵌入 MDP"的落地形式**。

**转移**：制度自动机推进 σ；τ 递减；被选中单元进入 S2→S3→S4；未推进且 τ=0 → S5。

**奖励**（按年折现，γ≈0.93 对应 7% 社会折现率）
```
r_t = Σ_k w_k · ΔObj_k(p_t → p_{t+1})        七目标增量，pSO 的 objs.py 直接可用
    − λ_c · ConvertCost(f_old → f_new)         CCM.csv 已有非对称转换成本矩阵（对角 0；农业→生态 85 而反向 20）
    − λ_d · Disruption(在建单元数, 邻域叠加)     多期施工干扰，静态模型无法建模
    − λ_e · ExpiryPenalty(进入 S5 的单元)        计划失效损失
```

**目标产出**：训练后逐单元逐年输出 `Q(act) − Q(wait)`，得到一张
**行动日程表**（哪年动哪些单元、转成什么），并对每个未选中单元给出"再等几年"的建议。
这是纯空间优化模型在原理上无法产出的东西。

### 与竞争工作的差别
MOGNNAC（SCS 2026）与 LUP-PPO 都在做"一次性分配"，且其 MDP 的"序贯"指的是
在同一时刻内逐格填充（sequential assignment within one decision），
**不是跨年度的制度时序**。本方案的 S5 冷却期机制与年度配额约束，两者均未建模。
"值不值得现在动"这个问题在它们的形式化里不可表达。
