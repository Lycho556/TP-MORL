## 2. 它到底做了什么（与你的课题逐项对照）

**问题（MOPBLUAP）**：邻里尺度、**矢量（地块）**为单元的多目标用地-密度分配。特色是显式纳入了以往被栅格模型抹掉的空间特征：**地块面积差异、建筑密度分配、设计考量**（用地/密度与临街道路宽度和功能的层级相容性、相邻地块密度差异、地块高度与街宽比例）。目标体系挂在**城市韧性 + 智慧城市规划**双框架下（风险水平 Rij、单位建筑面积排放因子 Ej、可再生能源设施布局潜力 PENijd、街道相容性 SCMjr）。

**方法（MOGNNAC）**：
- GNN 编码器在**地块邻接图**上传播地块间信息，得到节点嵌入作为状态；
- **每个目标一个独立 critic**，输出向量值 Q(s,a)，**不做标量化**——这是它相对既有单目标空间RL的主要卖点；
- actor 的损失是**超体积贡献** ΔHV(yt,P) = HV(P∪{yt}) − HV(P)，即"这个新解把帕累托前沿扩张了多少"，用蒙特卡洛或维度扫描近似；配 ε-支配与拥挤距离过滤维护帕累托档案；
- 对比对象是 **NSGA-II 与 MOPSO**（各调参后跑30次），指标为 D / MID / MS 与覆盖率。MOGNNAC 覆盖率 0.80（对 NSGA-II）、0.83（对 MOPSO），**均值更优但最坏情况不必然更优**。

**案例区**：**伊朗德黑兰第二区 Shadman 邻里，4065 个地块**，易受地震、洪涝等风险。7 类用地（居住、绿地、教育/医疗/文化/体育/商业各分地区级与非地区级），4 个密度等级。

**代码**：作者提供了"dummy case 的草图代码"公开下载（Google Drive 链接，见论文 Data availability），完整版需学术用途申请。

## 3. 三个可以直接拿走的技术点

**(1) 一次性 vs 序贯赋值的取舍论证 —— 这段是给你写方法论证的现成素材**
作者明确对比了两种 MDP 设定：一次性（同时给所有地块定用地-密度，赋值完成后一次性评估）与序贯（每步选一个地块赋值，逐步转移到中间状态）。他们选一次性，理由是：本问题的部分目标（Z2、Z3）与全局约束（用地总量上下界）**只有在完整方案生成后才能评估**；序贯设定虽允许基于既有赋值做条件决策、便于跨时间的策略性决策，但代价是状态转移频繁、episode 过长、**中间奖励难以定义**，且多目标与全局约束在该设定下难以处理。

**这段对你有双重价值**：①它承认序贯设定的优势正是"跨时间策略性决策"——也就是你要做的；②它把序贯设定的三个困难点明确列了出来（中间奖励定义、episode 长度、全局约束），**这就是你必须在方法上正面回答的三个问题**。你的优势在于：法定分期本身给了天然的时间粒度（年）与天然的中间奖励锚点（每期的施工扰动成本与已实现服务改善），不必像纯序贯那样人为设计中间奖励。

**(2) 动作掩码机制可以原样复用**
它在 Pareto-actor 里做动作掩码：当地块 v 不能接受用地类型 l 与密度 d 时，直接令 π(av,ld)=0，在采样分布之前置零。**这与我们层面2设想的"法定资格窗口掩码"是同一机制**——你只需把掩码条件从"用地相容性"换成"该更新单元在本决策年是否处于计划有效期内 / 是否已批复 / 是否已失效"。可以引用它作为掩码可行性的先例。

**(3) 约束处理三策略与选择理由**
可行性处理有三条路：丢弃不可行解、修复不可行解、惩罚不可行解。它因"丢弃可能导致某个 episode 的档案为空并在训练中反复出现"而未选丢弃，转向惩罚（把约束违反作为奖励向量的额外维度，D = 目标数 + 约束惩罚数）。你处理硬性法规约束时，可以据此论证：**能掩码的用掩码（硬约束），只能事后判定的进奖励向量（软约束）**。

## 4. 你的选题定位（结合 LUP-PPO 一并看）

现在两篇竞争工作的边界很清楚：

| | LUP-PPO (2026) | MOGNNAC (SCS 2026) | 本课题 |
|---|---|---|---|
| 空间单元 | 地块 | 地块（矢量） | 地块 / 更新单元 |
| 案例区 | **深圳**（华强北、东门） | 德黑兰 Shadman | 深圳（光明 + 全市训练） |
| 多目标机制 | 自适应双目标加权（标量化） | 向量值 critic + 超体积（无标量化） | 待定，可借 MOGNNAC |
| 决策结构 | 单期 | **单期一次性赋值** | **多期（按年）** |
| 时间维 | 无 | **无，且自陈为未来方向** | 核心贡献 |
| 制度约束 | 规划先验知识迁移 | 设计/相容性/总量约束 | **法定资格窗口与分期时序** |

**差异化表述可以这样写**：既有地块级用地分配RL（无论标量化加权还是向量值critic）均在单一规划期内一次性生成空间配置，其局限已被作者自身指出；本研究把决策结构从"单期一次性"改为"按年多期"，并以城市更新法定时序（计划有效期、延期、失效、分期实施）作为动作可行性的外生时变约束，从而使方法适用于**建成区渐进式更新**而非白地一次性布局。
