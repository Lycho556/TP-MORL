# 项目现状汇报：存量更新的时序决策模型 —— 数据来源与政策依据核实

**汇报日期**：2026-09-05
**案例区**：深圳市光明区
**目标期刊**：IJGIS

**本次汇报重点**：与深圳大学黄冠老师（土地利用与城市形态方向）的访谈，以及经其转询**深圳市规划局在职人员**得到的实务答复，对模型的制度设定构成了外部核实。本文把这些核实结果、条文原文、全部数据来源与模型机制逐条对应起来。

---

## 一页摘要

**项目在做什么。** 现有把机器学习／强化学习用于国土空间规划的工作，回答的是"这块地理想状态下该是什么功能"，产出一张最优用地图。本项目改问另一个问题：**"这块地现在值不值得动，还是再等几年"**，产出一张有年份的行动日程表。技术上定位为空间耦合的多目标最优停止问题。

**为什么这个问题是真问题。** 深圳存量更新不是"一次性重新分配土地"，而是一条**有法定时钟的通道**：立项 → 计划有效期倒计时 → 期内未获批则计划失效 → 拆建各需若干年 → 每年可推进的单元数受行政与财政能力限制。这条时钟上的每一环都是时序量，都不在用地类型里，所以静态配置模型结构上无法表达它。

**本次汇报的核心进展。** 模型的制度设定中原有两个参数缺乏依据，其中一个恰好承载了项目最核心的主张（"等待有代价，所以何时动才是决策"）。经访谈与规划局转询核实，这两个参数现在都有了实务依据；其中一条的核实结果**比原设定更严**，反而加强了项目立论。同时获得一条评价方法上的修正、一条结构性机制提示，并更正了一处条文引用错误。

**审批时间轴的来源值得单独说明。** 《城市更新单元规划批准基本情况》表内并没有审批日期列，但**文件本身是按年度窗口切分的**（2018.01–2019.11、2019.12–2020.11、2020.12–2021.11、2021.12–2022.11）——把四个文件分别读入再打上窗口标签，就得到 271 个已批单元规划的年度分箱审批时间。模型的时钟不是构造的，而是有真实数据支撑的。此外，平台数据不含有效期条款，这部分只能从公告正文逐份提取。

**标定策略是"全市标定、光明应用"。** 配对表由全市 269 条已批城市更新单元规划与对应计划公告匹配而成。光明区自身更新样本太少（平台 14 个、公告表 52 条），不足以标定审批概率，因此制度参数在全市样本上标定，再应用于光明区的空间底图。

**决策对象是"单元"而不是"格子"。** 光明区已批单元的拆除面积中位数是 4.4 公顷（约 4.4 个百米格）。若按格子决策，动作空间是 12,454 维，且会产生"半个单元"这种法律上不存在的动作。改按单元决策后是 717 个候选体（格数中位 11，全部落在实证的 1–30 格区间内）——动作空间小一个半数量级，**且每个动作都对应一个法律上真实存在的对象**。

## 三、模型决策与实际政策的对应关系

模型不是把政策"大致参考"了一下，而是把制度流程直接编码成状态机的转移规则。

### 3.1 功能区不按用地类型划，按"制度通道"划

理由是实测的：12 类用地里有 3 类在光明区格数为 0；真正处于存量更新状态的只占 32.6%，其余是生态、农业、既有道路市政。用同一套类别体系描述"拆掉一个 1990 年代工业区"和"把农田转成建设用地"，等于要求 agent 用同一个动作空间处理法定程序、时间尺度、成本量级、参与主体全都不同的两件事。

| 通道 | 格数 | 占比 | 时钟 | 可用动作 |
|---|---|---|---|---|
| P0 刚性禁动 | 4,915 | 28.3% | 无 | 无 |
| P1 产业拆除重建 | 2,469 | 14.2% | 计划有效期倒计时 | 立项／推进／放弃 |
| P2 旧居住 | 1,208 | 7.0% | 协议谈判周期 | 拆除重建／综合整治／等待 |
| P3 商服提升 | 339 | 2.0% | 无硬期限 | 整治／等待 |
| P4 设施存量 | 532 | 3.1% | 专项规划周期 | 改扩建／等待 |
| P5 农转用储备 | 3,537 | 20.4% | 年度用地指标 | 转用／保留 |
| P6 生态保育 | 4,369 | 25.2% | 无 | 无 |

P0 与 P6 合计 **53.5% 的土地完全不能动**。这是"存量更新"与"从零规划新区"最本质的差别，而它在用地类型分区里是隐形的。

### 3.2 每个单元的状态对应现实中的哪个环节

| 状态 | 含义 | 对应的现实环节 |
|---|---|---|
| S0 | 未立项 | 尚未列入更新计划，可申请（受年度配额约束） |
| S1 | 计划有效期内 | 已列入计划，倒计时中；可推进（按批准概率判定）或等待 |
| S2 | 单元规划已批 | 已获批，待实施 |
| S3 | 实施中 | 补偿、拆迁、招标、施工，产生邻域干扰 |
| S4 | 已完成 | 终止态，收益在**完工当年**才计入 |
| S5 | 计划失效 | 有效期届满未获批，退出 |

**"收益只在完工当年计入"这一条是让"等待"成为真决策的关键。** 如果收益在立项当年就给，那么越早动越好，问题退化为静态排序；只有收益在完工时才兑现、而完工需经过一条随机长度的审批与施工链条，"现在动还是再等"才构成权衡。

### 3.3 每条规则的依据等级

| 模型规则 | 取值 | 依据类型 | 具体出处 |
|---|---|---|---|
| 计划有效期 | 3 年 | **实测标定** | 109 对配对的时滞中位数恰为 3.00 年 |
| 延期上限 | 2 年 | **实测标定** | 总上限 5 年可覆盖 70.6% 的实际案例 |
| 逐年批准概率 | 17.4%／21.2%／23.9%／27.7%／17.9% | **实测标定** | 109 对配对的逐年条件批准率 |
| 年度立项配额 | 3 个 | **实测标定** | 光明区 2011–2018 计划公告年均 3.1、上限 6 |
| 有效期／延期的法定上限 | 2 年 + 1 年，原则上仅可延期一次 | **条文** | 深规划资源规〔2019〕4 号第三十二条 |
| 失效认定 | 草案公示结束 3 个月内未获批准、且已过有效期未延期 | **条文** | 深建规〔2025〕4 号 |
| 建设周期 | 拆除重建 5 年、微改造 3 年 | **实务核实**（原为自设） | 见 §4.1 |
| 失效后能否重报 | 规划期内不可再动 | **实务核实**（原为自设，条文中不存在） | 见 §4.3 |

规划期设为 15 年，时间步长 1 年。全部参数的分级明细见参数依据分级表（A 条文／B 实测标定／C 自设／D 情景）。

## 四、外部实务核实结果

以下五条中，前两条改变了模型参数，第三条改变了评价方法，第四条提示了一处结构性缺失，第五条是对建模态度的建议。

### 4.1 建设周期：原设定偏短

**核实结果**：从规划获批到建成一般涉及补偿、拆迁、招标、建设、验收，3 年偏短，**可能需 5 年以上**，且项目之间的差异不小；若仅为微改造，3 年是合适的。

**落地**：建设周期由全局常量 3 年改为按通道／动作分档——拆除重建 5 年、综合整治／微改造 3 年。模型的动作空间本来就区分这两种动作（P2 通道明确含"拆除重建／综合整治"两选），接得上，不需要改结构。

**受限于数据**：单元表没有"更新方式"字段（见第六节），只能按通道／动作近似，无法逐单元判别。

**一处连带发现（核实中未提及，是我方推出的）**：建设周期改为 5 年后，立项 → 获批（中位 3 年）→ 建成（5 年）= **8 年以上**，而规划期 15 年。这意味着**第 8 年之后立项的单元在规划期内无法交付**。这既强化了"时间窗是硬约束"这一立论，也需要检查后半程的决策是否退化。

### 4.2 一处条文适用期问题（自行发现并已更正）

条文写的有效期是 **2 年**，而实测中位时滞是 **3 年**，表面看像"条文与现实脱节"。我一度也这样认为并写进了对外说明。**核实后这是错的。**

深规划资源规〔2019〕4 号第三十二条第一句限定适用于"**本规定施行后批准的**更新单元计划"，即 2019-03-15 之后。而标定用的 109 对配对来自 **2010–2018 年**，当期适用的是深规土告〔2010〕16 号，**那批旧计划本无有效期之设**（该文已被 2019〕4 号废止）。深建规〔2025〕4 号之所以要求各区对"公告未明确有效期"的存量计划补设有效期，正是这批旧计划原本没有有效期的直接证据。

**所以不是条文脱节，是拿新规去量了旧数据。** 结论有两点：一是实测的 3 年是旧制度下的真实时滞，标定站得住；二是现行法定窗口（2 + 1 = 3 年）比模型用的 5 年紧，须作为情景对照单独跑一组。这处更正已在访谈中主动说明。

### 4.3 失效后能否重报：核实结果与原设定相反，且对项目有利

这是本次最重要的一条。

**背景**：模型原设定"计划失效后冷却 2 年，之后可重新立项"。这个值缺乏依据——两份条文全文检索"冷却"**0 处**、"重新申报"**0 处**，即这条规定在深圳的更新法规中不存在。而项目最核心的主张"等待是有代价的、所以何时动才是个真决策"，几乎全部压在这条设定上。这是整个模型最脆弱的一处。

原本担心的是**设重了**：若实务中失效单元大都能顺利重报、代价很小，那这条"风险"就是虚构的，立论会塌。

**规划局在职人员的答复**（经黄冠老师转询）：

> 一般在一个规划期内，如果政府给更新方案否定了，基本认为这块地暂不需要更新，**也没有下一次申请的说法**。

**这与原设定方向相反，且更严。** 实务口径是一个规划期内**不存在"下一次申请"**——一旦被否，该单元在本轮规划期内退出可动集合。

**落地**：失效状态由"停 2 年后回到未立项"改为**规划期内的吸收态**。敏感性扫描范围随之调整，原先设想的"零冷却"档已知不符合实务，不再作为立论的压力测试。

**对项目的意义**：核心设定**不是设重了，而是设轻了**。现实中"等待"的代价比模型写入的更大，立论比原先更站得住。最脆弱的那一处现在有了实务依据。

**一处口径差须在论文写明**：该答复讲的是**方案被否决**，而模型中该状态的触发条件是**有效期届满未获批**（被动失效）。二者是否等同未经确认，属转述。论文将表述为"两种情形均按规划期内吸收态处理，并以 2 年冷却作为宽松情景对照"，不夸大答复的覆盖范围。

### 4.4 评价粒度：一条方法学修正

**核实中提出**：决策单位不是"年"而是"批"；各项目的获批时间并不同步，实施年份差别可能较大。

**我方核算（光明区 2010–2018 计划公告）**：共 **20 批**，平均每年 2–3 批，相邻批次间隔中位数**约 4 个月**，每批中位 1 个单元。

**结论一分为二，这是一次有价值的双向校核**：

- **公告侧**：该前提不成立——实际公告节奏比一年还密，模型的"一年一步"已经是对公告流的**聚合**。**步长不必改。**
- **实施侧**：该担心成立——同批单元的获批与实施年份确实分散，而模型已用逐年批准概率把这一段当随机处理，机制上已覆盖。
- **方法学后果（最重要）**：既然实施年份本身不可精确预测，**就不应拿"模型第几年"逐年去比真实年份**——那超出了现象本身支持的精度。历史回测与顺序验证应改为只比先后次序（Spearman 秩相关）或按 3 年／5 年分箱比较。

### 4.5 产业用地异地置换：一条结构性机制提示

**核实结果**：工业用地转换是逐个项目单独议定的。典型两条路径——一是等土地使用权到期，政府收回再重新出让；二是上层规划有迫切需求时，在**别处异地补划产业用地**、把企业腾挪过去，原址随即转换。

**为什么重要**：模型现在把每个单元当**独立决策**，没有配对动作，也没有产业用地总量守恒约束。而第二条路径本质上是"**配对动作 + 指标守恒**"——动这块地的前提是别处补出一块，且产业用地总量不减。

**可能的解释力**：这或许能解释前序工作中一个反常发现——最高适宜性地块反而最晚开发。现实中它们要等到有可置换的接收地才动得了。

**处理**：需改动作空间与约束，工作量较大，列为下一轮结构性改动，本轮先记录。

### 4.6 一条关于建模态度的建议

实务方的建议是：研究性建模的假设只要符合大致的政策导向、能够自洽自明，即可成立，**不必逐条受限于条文本身**。

**如何采纳**：这解除的是"每个参数都必须有条文出处"的自我约束。但对期刊审稿，"自洽"仍需落成可查的东西，因此做法不变——继续把每个参数标为 A（条文）／B（实测标定）／C（自设）／D（情景），C 级一律写明"设定值，须敏感性分析"。区别在于不再为 C 级参数硬找条文依据，也不再因其无出处而回避。

## 六、已知数据缺口（须在论文局限中写明）

1. **平台上没有任何更新单元的边界几何。** 全部 4,841 个数据集中不含更新单元矢量，记录只有"单元名称 + 街道"，空间定位须另行处理——这是最大的剩余风险。
2. **光明区建筑建成年份缺失。** 市级建筑物表仅有编码／名称／地址三字段；有"竣工时间"的是福田区表（17,124 条），不在光明。因此"地块状态生命周期"这一层缺少年龄变量。
3. **单元表无"更新方式"字段。** `类型` 列只有"计划公告""规划批准"两值，无法逐单元判别拆除重建与微改造，只能按制度通道／动作近似（直接影响 §4.1 的落地精度）。
4. **光明区自身更新样本量小。** 已由"全市标定、光明应用"的设计化解，但须在方法学部分说明这一取舍。
